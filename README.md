# Chip-8-emulator
A bare bones chip-8 emulator

# Why I did this project
I have always been interested in low level. In the past I have messed around with assembly and a bunch of digital electronics, but then I saw this ysws on Hachclub. It was exactly the type of programming project I've been wanting to pick up for a while, so I threw myself in head first. It was very confusing but fun to learn so much at once.

# Running Chip-8
To run my emulator you just need the binary main. To run it simply type in ./main <scale> <delay> chip8program.ch8 in your terminal. Chip-8 is suprisingly capable for what it is and there are tons of talented developers who write roms for it.
